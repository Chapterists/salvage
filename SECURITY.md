# Security

## Reporting a vulnerability

Please report security problems privately through GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/Chapterists/salvage/security) of this repository.
2. Choose **Report a vulnerability**, or go straight to the [report form](https://github.com/Chapterists/salvage/security/advisories/new).

Don't open a public issue, discussion or pull request about it. Only you and the maintainers can see a private report, and we'll reply and work through the fix with you there.

Useful things to include: what you found, how to reproduce it, which commit or version you tested, and what you think the impact is.

## Leaked secrets

If you find a password, token, key or other credential anywhere in this repository or its history, report it the same way, through private vulnerability reporting. Don't post it, quote it, or link to the line in public.

If the secret is yours and you pushed it by mistake, revoke or rotate it right away, then report it. Removing the file doesn't remove it from git history, so treat any pushed secret as exposed.

## Supported versions

Salvage hasn't released anything yet. Reports against the `main` branch are welcome.

## Problems in Unreal Engine itself

If the problem is in Unreal Engine and not in Salvage's own code, report it to Epic Games through their security reporting process. We can't fix the engine here, and engine details shouldn't be published in this repository.
