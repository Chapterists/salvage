---
title: Where Unreal's memory goes on a 16 GB machine
date: 2026-11-06
---

A new chart explains where an Unreal Engine 5.8 game and the editor spend memory by default: the texture and Nanite streaming pools, virtual shadow maps, Lumen's surface cache, the render target pool, the audio cache, garbage collection and shader compile workers. For each one it gives the default and the setting that controls it. It describes defaults only. Nothing has been changed or measured yet.
